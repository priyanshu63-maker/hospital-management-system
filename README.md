# Hospital Management System

## Project Overview

A C++ based Hospital Management System integrated with Linux System Programming and a Linux Character Device Driver.

## Features

- Patient management
- Doctor management
- Appointment booking
- Medical records
- Patient monitoring
- Linux process and thread programming
- File handling and logging

## Technologies

- C++
- C
- Linux / WSL2
- GCC / G++
- POSIX Threads
- Linux Character Device Driver
- Make

## Project Structure

main.cpp
hospital.cpp
hospital.h
driver/monitor.c
driver/Makefile

## Patient Monitoring

The application communicates with /dev/patient_monitor to read simulated patient vital signs.

Example: Heart Rate 78 BPM, Temperature 98.4 F, SpO2 98%, Status NORMAL.
